# DeadLink Watchdog - Version 2.0 Roadmap

## Subscription Plans

### Free Tier
- Up to 3 websites
- Monthly crawl frequency
- Basic email notifications
- 7-day data retention
- Standard support

### Pro Plan
- Up to 25 websites
- Weekly/Daily crawl frequency
- Email + Webhook notifications
- 30-day data retention
- Priority support
- Custom crawler settings
- Advanced reporting
- API access

### Enterprise Plan
- Unlimited websites
- Custom crawl frequency
- All notification methods
- 90-day data retention
- Dedicated support
- Custom integrations
- White-label reports
- Multi-user access
- SLA guarantees
